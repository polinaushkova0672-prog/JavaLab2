# Лабораторная работа №2 — Мышь в лабиринте (Q-learning)

Оконное приложение на **Java 21, Swing**. Реализует обучение с подкреплением (Q-learning) для мыши, которая ищет сыр в лабиринте.

## Задание

Мышь ищет в конце лабиринта **самый большой наградной сыр (+Z)**. Мышь должна **пить воду** (меньшая награда **+x**). Мышь хочет **избежать электротравмы (−y)**. На каждом шаге мышь выбирает направление, а среда сообщает величину выигрыша или проигрыша. Мышь накапливает **сумму выигрыша/проигрыша**.

Размер и схему лабиринта задаёт пользователь.

## Интерфейс

Окно разделено на **две вкладки**.

### Вкладка «Главная»
- **Размер поля** — высота и ширина (2–200), кнопки «Создать лабиринт» и «Чистое поле».
- **Редактирование схемы** — выбор инструмента (Проход, Стена, Вода, Ток, Старт, Сыр).
- **Обучение мыши (Q-learning)** — число попыток, кнопки «Запустить обучение» и «Прервать».
- **Демонстрация** — кнопки «Один ход мыши», «Вернуть мышь», «Пройти по выученному пути».
- **Статистика** — шаги, накопленная сумма, порции воды, пройденные эпизоды, записи в Q-таблице.

### Вкладка «Награды»
- **Сыр (+Z)**, **Вода (+x)**, **Электротравма (−y)** — настройка подкрепления.
- Кнопка **«Задать подкрепление»**.
- **Легенда** — цвета всех элементов.

### Верхняя панель
- **Слайдер «Масштаб»** — от 20% до 200%.
- Кнопка **«Открыть лог»** — открывает отдельное окно с логом шагов.

## Использование

1. **Создайте лабиринт:** задайте высоту и ширину, нажмите «Создать лабиринт». Старт — в левом нижнем углу, сыр — в правом верхнем. Генератор DFS гарантирует путь.

2. **Отредактируйте схему** (по желанию):
   - Выберите инструмент.
   - **Левый клик** — поставить. Повторный клик по тому же объекту — убрать.
   - **Правый клик** — очистить клетку.
   - **Перенос старта/сыра** — выберите инструмент «Старт» (или «Сыр») и кликните по пустой клетке.

3. **Настройте награды** (вкладка «Награды»), нажмите «Задать подкрепление». Изменение наград сбрасывает обучение.

4. **Обучите мышь:** задайте число попыток и нажмите «Запустить обучение». «Прервать» останавливает обучение.

5. **Посмотрите результат:** нажмите «Пройти по выученному пути» — мышь пойдёт по выученной стратегии.

6. **Ручное управление:** кнопки направления или клавиши **↑ ← ↓ →**.

## Правила и принятые решения

- **Сыр** даёт **+Z** и завершает попытку.
- **Вода** даёт **+x** при первом посещении за попытку. В новой попытке восстанавливается. Одноразовость исключает бесконечное накопление награды.
- **Электротравма** даёт **−y** при каждом входе.
- **Пустая клетка** — **−1** (стимулирует искать короткий путь).
- **Удар в стену/границу** — **−3** (мышь остаётся на месте).
- **Сумма** отображается в статистике.
- **Лог** содержит все шаги (можно прокручивать, копировать, очищать).

## Алгоритмы

### Генерация лабиринта (DFS с возвратом)
Поле заполняется стенами. Стартовая вершина помечается посещённой, затем выбирается случайный непосещённый сосед и прорезается проход. Если таких соседей нет — алгоритм возвращается к предыдущей вершине. Работа заканчивается после обхода всех вершин. Между вершинами оставляется клетка стены; для чётных размеров сыр соединяется с ближайшим коридором. Стек хранится явно, без рекурсии. Проверка достижимости — поиском в глубину.

### Q-learning (формула Беллмана)
```
Q(s,a) ← Q(s,a) + α × [reward + γ × max Q(s′,a′) − Q(s,a)]
```
- α = 0.25 — скорость обучения.
- γ = 0.95 — дисконт.
- ε — исследование, уменьшается с 0.9 до 0.05.
- При достижении сыра будущая награда = 0.
- Состояние включает множество выпитых клеток воды.
- Лимит попытки: `min(10000, строки × столбцы × 10)`.
- Лимит Q-таблицы: 100 000 состояний.
